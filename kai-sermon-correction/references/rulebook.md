# 설교 발표 교정본 규칙서

## 색상 규칙 (HTML)

| 구분 | CSS 클래스 | 색상 | 스타일 | 발표 시 |
|------|-----------|------|--------|---------|
| 보존 | `.keep` | `#e8e8e8` | 일반 | ✅ 읽음 |
| 삭제 | `.del` | `#444` | 삭제선 | ❌ 건너뜀 |
| 수정 대상 | `.edit` | `#6B3333` | 삭제선 | ❌ 건너뜀 |
| 추가/요약 | `.add` | `#5B9FFF` | 일반 | ✅ 읽음 |
| 성경 구절 | `.verse` | `#c8d8f0` | 왼쪽 파란 보더 | ✅ 읽음 |
| 배경설명 | `.bg` | `#6BBF6B` | 왼쪽 녹색 보더 | 📚 참고 |

## 편집 원칙

### 원문 보존
- 원문의 모든 문장이 HTML에 존재 (삭제선 포함)
- 문장 순서 절대 불변
- 히브리어/그리스어 원문은 해석 유지 + 한글 음역 병기

### 성경 구절 (.verse)
- 절대 수정·삭제·요약 금지
- 한글 개역개정 기본
- 출처 `.ref` 스팬으로 표시

### 삭제 판단 (.del)
- 앞에서 이미 말한 반복·부연
- 장황한 수사적 표현
- 흐름에 기여하지 않는 전환 멘트 ("자, 이제...", "깊이 들어가 봅니다")
- 과도한 상세 설명
- 수사적 질문 나열 (핵심 하나만 남김)

### 수정 판단 (.edit → .add)
- 너무 긴 문장 축약
- 더 간결한 표현 가능
- 과도한 구어체
- 여러 문장 → 한 문장 요약
- 맨 마지막 기도문은 발표자료에서 제외

### 보존 판단 (.keep)
- 핵심 메시지·주장
- 필수 연결 문장
- 인상적 표현·비유
- 중요한 신학적 설명
- 이미 간결한 문장

### 추가 삽입 (.add 독립)
- 삭제 후 흐름 연결 필요 시
- 긴 설명 삭제 후 한 줄 요약 필요 시
- 단락 전환 브릿지 문장
- 원문 의미를 벗어나지 않을 것
- 효과적 전달을 위해 질문/답변 또는 첫째/둘째/셋째 구분 가능

### 배경설명 (.bg)
- 해당 구절/주제 바로 아래에 삽입
- 포함 요소: 원어 분석, 역사적 배경, 영어 번역 비교, 용어 해설, 신학적 연결
- 3~8문장 이내, 필요 시 여러 블록
- 성도 눈높이, 설교 주제와 연결
- 원어 표기: `원문 (한글 음역, 영문 음역) = 뜻`
- 영어 번역 비교: 한글 번역과 원문 차이 시 ESV/NIV/NKJV/NLT/YLT

## 구조 규칙

### 단락 나누기
- 큰 주제 전환 시 `<hr>` + `<h2>` 섹션 제목
- 섹션 제목은 `.add` 스타일 파란색 배경 라벨
- 예: "도입 — 누가 내 인생의 조종석에 앉아 있는가?"

### 히브리어/원어
- `.hebrew` 클래스: RTL, 큰 폰트
- `.greek` 클래스: 그리스어
- 장황하면 .edit → .add로 축약

### 기도문
- 동일 규칙 적용
- 맨 마지막 기도문은 발표자료에서 제외 (삭제 처리)

## 토의 포인트 (.discuss)
- 요청 시에만 포함 (기본: 미포함)
- 핵심 신학 주제/삶 적용 포인트 바로 아래 삽입
- 구조: `discuss-title` + 🔍 생각 정리 (분석) + 선택적 비교표 + ❓ 함께 나눌 질문 3~5개
- 원문 목장 나눔 질문 참고 후 설교 흐름에 맞게 재구성

## HTML 패턴
- 인라인 혼합 색상: `<span class="keep/del/add">` 사용
- 섹션 구분 제목: `<h2 class="add">제목</h2>` — 원문에 없는 흐름 구분
- 단일 색상 문단: `<p class="keep">` 블록 클래스 사용 가능
