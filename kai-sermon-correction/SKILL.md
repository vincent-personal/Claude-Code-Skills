# Sermon Correction (설교 발표 교정본)

설교 원문 → 발표용 축약 교정본 (HTML + Notion) 변환 스킬.

## Workflow

### Step 1: 정보 수집

사용자에게 다음을 질문한다 (누락된 항목만):

1. **발표 시간**: 10분 / 15분 / 20분 / 30분
2. **설교 원문**: 텍스트 또는 파일
3. **출력 형식**: HTML만 / Notion만 / 둘 다 (기본: 둘 다)
4. **배경설명(녹색)**: 포함 여부 (기본: 포함)
5. **토의 포인트(노란 박스)**: 목자 모임/소그룹용 💬 블록 포함 여부 (기본: 미포함)

발표 시간별 목표 분량 (분당 250자, 보존+추가 합산):
- 30분 → ~20% 삭제 → ~7,500자
- 20분 → ~40% 삭제 → ~5,000자
- 15분 → ~55% 삭제 → ~3,750자
- 10분 → ~70% 삭제 → ~2,500자

### Step 2: 규칙서 로드

`references/rulebook.md`를 읽어 색상 규칙, 편집 원칙, 검증 체크리스트를 확인한다.

### Step 3: HTML 생성

1. `assets/template.html` 내용을 읽어 작업 기반으로 사용
2. 규칙서의 색상·편집 원칙에 따라 원문 편집
3. 원문의 **모든 문장** 보존 (삭제선 포함), **순서 불변**
4. 성경 구절: 한글 개역개정 기본. 원문과 차이 시 영어 번역(ESV/NIV/NKJV/YLT) 비교
5. 히브리어/그리스어: 원문 + 한글 음역 + 뜻 표기
6. **출력 경로**: 현재 Claude Code 세션이 열린 폴더(Primary working directory) 아래 `docs/` 디렉터리에 저장
   - 폴더 없으면 자동 생성: `mkdir -p {SESSION_ROOT}/docs`
   - 파일명: `sermon-{설교제목}-{YYYYMMDD}.html` (공백은 하이픈으로, 한글 허용)
   - 예: `docs/sermon-참잘사는사람-20260527.html`
7. 저장 완료 후 전체 경로를 사용자에게 알린다

### Step 4: Notion 생성 (요청 시)

부모 페이지: **"목자모임 설교 정리"** (ID: `2fd91d71-efea-806a-a881-f8ede6e0c676`)

Notion 색상 매핑:
| 구분 | Notion 표기 |
|------|------------|
| 보존 | 기본 텍스트 |
| 삭제 | `~~text~~ {color="gray"}` |
| 수정 대상 | `~~text~~ {color="red"}` |
| 추가/요약 | `{color="blue"}` |
| 성경 구절 | 인용블록 `{color="purple"}` |
| 배경설명 | `{color="green"}` |

상단에 범례 포함. `notion://docs/enhanced-markdown-spec` fetch 후 사용.

### Step 5: 검증

규칙서의 검증 체크리스트 수행 (원문 보존, 순서, 성경 구절, edit→add 쌍, 자연스러운 흐름, 목표 분량).

## 배경설명 (녹색) 작성 가이드

해당 구절/주제 바로 아래에 삽입. 다음 요소를 조합:
- **히브리어/그리스어 원문**: 핵심 단어 + 음역(한글) + 뜻
- **역사적 배경**: 시대·인물·사건 맥락
- **영어 번역 비교**: 한글 번역과 원문 차이 시 ESV/NIV/NKJV/NLT/YLT
- **용어 해설**: 성도 눈높이 설명
- **신학적 연결**: 구약↔신약, 설교 주제 연결

원어 표기 형식: `אֲדֹנִי (아도니, adonai)` / `Χριστός (크리스토스, Christos)`

정확성 최우선 — 불확실하면 웹 검색으로 확인.

## 토의 포인트 (.discuss) 작성 가이드

토의 포인트는 Step 1 질문 5번에서 포함 요청 시에만 삽입. 핵심 신학 주제 또는 삶 적용 포인트 바로 뒤에 위치.

### HTML 구조
```html
<div class="discuss">
  <div class="discuss-title">💬 목자 생각 / 토의 포인트</div>
  <p>🔍 <strong>생각 정리</strong></p>
  <p>신학적·지성적 분석 (2~4문장). 원어 의미, 역사적 맥락, 현대 적용 연결.</p>
  <!-- 비교가 유용할 경우 표 삽입 -->
  <table>
    <tr><th>항목</th><th>내용</th></tr>
    <tr><td>...</td><td>...</td></tr>
  </table>
  <p>❓ <strong>함께 나눌 질문</strong></p>
  <p>1. 질문 1</p>
  <p>2. 질문 2</p>
  <p>3. 질문 3</p>
</div>
```

### 내용 원칙
- **🔍 생각 정리**: 목자가 소그룹 인도 전 스스로 정리해야 할 신학적·지성적 분석
  - 원어 의미 확장, 역사적 사건 맥락, 구약↔신약 연결, 현실 적용 통로
  - 비교가 유용하면 표(table) 사용 (예: 모세 vs 엘리야, 이집트 신 vs 여호와)
  - 영화·문학·시사 레퍼런스 활용 가능 (공감대 형성)
- **❓ 함께 나눌 질문**: 소그룹 나눔용, 3~5개
  - 개인 경험 연결 질문 ("~한 적이 있나요?")
  - 말씀 적용 질문 ("어떻게 ~할 수 있을까요?")
  - 공동체 나눔 질문 ("우리 공동체에서 ~하고 있나요?")
- 전체 분량: 생각 정리 3~6문장 + 질문 3~5개. 지나치게 길면 2개 블록으로 분할.
- 원문 목장 나눔 질문이 있으면 참고하되, 설교 흐름에 맞게 재구성

## HTML 구조 패턴

### 인라인 혼합 색상 (`<span>` 패턴)
한 문단 안에 여러 색상이 섞일 때는 블록 클래스 대신 인라인 `<span>` 사용:
```html
<p>
  <span class="keep">보존할 텍스트</span>
  <span class="del">삭제할 텍스트</span>
  <span class="add">추가 요약</span>
</p>
```
단일 색상 문단은 `<p class="keep">` 형식(블록 클래스) 그대로 사용.

### 섹션 구분 제목 (`<h2 class="add">` 패턴)
원문에 없는 흐름 구분 제목을 추가할 때 `.add` 클래스 사용:
```html
<h2 class="add">섹션 제목 — 핵심 주제 한 줄 요약</h2>
```
`.add`이므로 발표 시 읽음 대상. 청중 맥락 전환 역할. 큰 주제 전환 시 `<hr>` 앞에 배치.

## 독립 관리 원칙

HTML과 Notion은 독립 관리. 명시적 지시 없으면 요청받은 쪽만 수정.
