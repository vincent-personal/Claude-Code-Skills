# 레퍼런스 1:1 대조 — 방법과 함정

> **스크린샷 육안 대조로는 12.5px 와 13px 을 가릴 수 없고, 접힌 화면 아래는 보이지도 않는다.**
> 양쪽 DOM 을 **같은 규칙으로** 읽어 글자마다 스타일을 대조한다.
> 디자인 원본(HTML 캔버스·Storybook·배포된 원본)이 있을 때만 쓴다.

비교 항목: **글자 크기 · 굵기 · 색 · 가로 위치 · 이웃 간 세로 간격**
+ 레퍼런스에만 있는 글자(**구현 누락**) · 구현에만 있는 글자

## 🔴 계측기 네 종을 **다 돌린다** — 하나만으로는 절반도 못 본다

| 계측기 | 무엇을 | 왜 따로 있나 |
|---|---|---|
| `audit-ref-diff.mjs` | **글자** | 기본 |
| `audit-ref-boxes.mjs` | **상자** — 칠·테두리·반경·그림자·크기 | 글자 프로브는 **직계 텍스트가 있는 요소만** 잰다. 카드 바탕·배지 알약·스위치 트랙·아바타 원이 **통째로 빠진다** |
| `audit-ref-boxes.mjs --hairlines` | **1px 구분선** | 레퍼런스는 별도 `<span>`, 구현은 `border-bottom` 인 일이 잦다. 섞어 재면 "상자 유무" 차이로 잡혀 잡음이 된다 |
| **오버레이** (`map` 에 `openIdx` 추가) | 서랍·시트·다이얼로그·토스트 | **화면 프로브는 오버레이를 한 번도 열지 않는다** |

라이트·다크 **양쪽**을 다 돌린다. "다크만 맞고 라이트가 어긋난" 전례가 있다.

### 상자 대조의 함정 둘

**① 짝짓기가 자리·크기 기준이라 완벽하지 않다.** 그래서 **짝을 못 찾은 것도 그대로 보고**한다.
숨기면 계측기가 거짓말한다.

**② 「화면 바탕과 같은 색」으로 걸러내면 안 된다.**
눈에 안 보이는 칠을 빼려고 그렇게 했더니, 라이트 팔레트에서 **흰 판이 페이지 바탕과 같은 흰색**이라
통째로 사라졌다. **부모가 실제로 칠한 색**과 견줘야 한다.

## 🔴 이 여덟 가지를 모르면 결과가 전부 거짓이 된다

### 1. 상자가 아니라 **글리프**를 재라
한쪽은 배지 **상자**(패딩 포함)를, 다른 쪽은 그 안의 **글자 span** 을 재면
**똑같이 그려진 화면도 매번 어긋난 것으로** 나온다.
```js
const rg = document.createRange();
rg.selectNodeContents(textNode);
for (const b of rg.getClientRects()) { /* 실제 글리프 자리 */ }
```

### 2. `position` 으로 부유 요소를 판정하지 마라
프레임워크가 페이지마다 붙이는 래퍼가 `absolute` 인 경우가 있다(Ionic 의 `.ion-page`).
그것으로 판정하면 **모든 화면에서 세로 간격 검사가 통째로 꺼진다** — 실제로 그렇게 되어
14px 여백 누락을 놓쳤다. **선택자로 지목**한다(`floating`).

### 3. 폰트가 준비될 때까지 기다려라
`await page.evaluate(() => document.fonts.ready)`.
안 그러면 폴백 서체로 잰 값이 나온다.

### 4. **아이콘이 그려질 때까지** 기다려라
SVG 가 비어 폭이 0 인 채로 재면 **그 옆 글자가 아이콘 너비만큼 밀린 것으로 잘못 잡힌다.**
끝내 안 차면 "이 화면의 가로 위치는 믿지 말라"고 **보고에 적는다.**

### 5. 테마는 **레퍼런스 자신의 토글 버튼을 눌러** 맞춰라
속성을 직접 쓰면 프레임워크가 다시 그릴 때 되돌린다.

### 6. 원점을 맞춰라
레퍼런스는 기기 프레임 안에 **상태바(시계)** 를 그린다. 앱에는 없다.
상태바 높이를 원점에서 빼지 않으면 **모든 y 가 통째로 어긋난다.**
안전영역도 마찬가지 — 레퍼런스가 `34px` 로 흉내 냈다면 앱에도 같은 값을 심는다.

### 7. **글자 폭은 비교하지 마라**
서체 대체(레퍼런스가 웹폰트를 못 불러오는 등)로 라틴 글자 폭이 정상적으로 다르다.
가로는 **왼끝·오른끝 중 하나만 맞으면 통과**, 가운데 정렬은 **중앙끼리** 비교한다.

### 8. 짝짓기는 **문서 순서가 아니라 세로 거리**로
같은 글자가 화면에 여럿이면 문서 순서로 짝지을 때 엉뚱한 짝이 생긴다.
**y 가 가장 가까운 것**끼리 짝짓는다.

## 🟡 캔버스가 글자를 쪼개는 문제

디자인 캔버스는 `{{ a }} · {{ b }}` 를 **요소 여럿**으로 그리고, 구현은 한 문자열이다.
그대로 짝지으면 조각 하나가 화면 다른 곳의 같은 글자와 엮여 **없는 차이**를 만든다.

**짝짓기 *전에*** 레퍼런스 쪽 조각을 이어 붙인다:
- 문서 순서로 최대 6조각까지 이어 보고, 공백·`·`·`:`·`,` 를 뺀 문자열이 앱 쪽 문자열과 같으면 합친다
- ⚠️ 구분자가 있는 **합성 줄만** 후보로 삼는다 — 그러지 않으면 나란한 숫자 타일 `2` 와 `1` 이
  다른 곳의 `21` 과 엮인다
- ⚠️ 레퍼런스에 그 문장이 **이미 통째로** 있으면 잇지 않는다(짝이 둘로 늘어난다)
- 앱에 있는 **개수만큼만** 이어 붙인다

## 🔑 편차가 나오면 **레퍼런스의 소스를 직접 읽어라**

계산된 값만 보면 원인을 못 찾는다. **구조가 다른 것**이 원인인 경우가 많다.

> **실제 사례.** 합계 줄 위 여백이 48px 이어야 하는데 44px 이었다. 소스를 열어 보니 —
> ```js
> // 레퍼런스: 별도 1px div + margin 2px 0
> div({ style: { height: 1, background: 'var(--border-subtle)', margin: '2px 0' } })
> ```
> ```scss
> // 구현: padding-top + border-top
> &__total { padding-top: 10px; border-top: 1px solid var(--border-subtle); }
> ```
> 레퍼런스 `10 + 2 + 1 + 2 + 10 ≈ 25px` vs 구현 `10 + 10 + 1 ≈ 21px` — **모자란 4px 의 정체.**
> 같은 수정이 다른 화면의 같은 편차도 함께 해결했다.

**원인을 못 찾겠으면 `advisor` 에게 레퍼런스 소스와 구현 코드를 함께 보여 주고 묻는다.**

## 🔴 "우리 결함"과 "레퍼런스 자체의 결함"을 가른다

원본을 100% 베끼는 것이 목적이 아니다. **원본이 틀렸으면 베끼지 않는다.**

| 판정 | 조치 |
|---|---|
| 우리 결함 | 고친다 |
| **레퍼런스 export 결함** | 고치지 **않고** `docs/` 에 **근거와 함께 기록** |
| 의도적 개선 | 마찬가지로 기록 |

실제로 가려낸 것: 막대그래프 막대가 4px 토막으로 뭉개짐 · QR 화면에 하드코딩된
`#F4F4F7`/`#A5A5B4` 가 라이트에서 안 읽힘 · 글자수 카운터 중복 표시 · 복붙 오타(`3개 블록`).

🔴 **"의도적 편차 N건"을 문서에 명시**하고 **그 외는 0** 으로 만든다.
판정이 애매하면 **`advisor` 에게 묻는다.**

## 🔴 보고할 때 범위를 정직하게 좁혀라

교차 검증(GPT-5.6)이 **"100% 동일"이라는 표현을 물리쳤다.**
잰 것은 "글자 프로브가 닿는 범위"였지 화면 전체가 아니었다.

- ❌ "레퍼런스와 100% 동일"
- ✅ "**글자·상자·가는선 프로브 범위**에서 편차 0 (의도적 편차 8건 별도 문서화).
      아이콘 모양·그림자 번짐·이미지 크롭은 프로브 범위 밖"

## 결과 읽는 법

### 🔑 "여러 화면에 반복되는 편차" 표를 먼저 보라
같은 편차가 12개 화면에 나오면 **화면 12개를 고치는 게 아니라 토큰/공용 컴포넌트 한 곳**을 고친다.
실제 사례: 헤더 규격(패딩 4/12 · 간격 6 · 뒤로 버튼 40×40)이 54개 화면에서 어긋났는데
공용 헤더 컴포넌트 하나로 해결됐다.

### "레퍼런스에만 있음" = 구현 누락 의심
탑 네비게이션이 통째로 빠진 것을 이 항목이 잡는다.

### 의도적 편차는 목록으로 관리하라
전부 0 이 되지는 않는다(폰트 대체·플랫폼 차이·의도적 개선).
**"의도적 편차 N건"** 을 문서에 명시하고, 그 외는 0 으로 만든다.

## 레퍼런스가 없다면

`audit-pixel.mjs` 의 **근접 불일치**(정렬 2~8px, 여백 1~5px)로 대신한다.
원본 없이도 "같은 값이어야 할 것이 어긋난 곳"은 잡힌다.
