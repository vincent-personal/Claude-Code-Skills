# 계측기 함정 — 오탐과 거짓 통과

> 계측기는 두 방향으로 거짓말한다.
> **오탐**(없는 결함을 만든다)은 신호를 묻고, **거짓 통과**(있는 결함을 숨긴다)는 더 위험하다.
> 아래는 실제 프로젝트에서 **모두 겪은 것**이다.

---

## 🔴 거짓 통과 — 있는 결함을 숨김 (더 위험하다)

### T1. 탐색 실패를 삼킴 — 최악
```js
try { await page.goto(url) } catch { continue }   // ❌ 절대 금지
```
15개 URL 이 **전부 실패해도 "문제 0건"** 이 나온다. 실제로 그렇게 되어 있었다.
UI 감사기는 `continue` 조차 안 해 **직전 화면의 DOM 을 이 화면의 결과로** 기록했다.

**고침**: 공용 `nav.mjs` — 앱 루트 존재 + 최종 경로 일치로 판정하고,
**실제로 연 수를 예정 수와 대조**해 부족하면 실패시킨다.
```
실제로 연 화면 448/448      ← 이 줄이 없는 감사기는 믿지 마라
```

### T2. 프래그먼트 이동은 응답이 `null`
같은 문서 안 이동(`/orders` → `/orders#pay`)은 Playwright `goto` 가 `null` 을 준다.
응답 유무로 판정하면 **정상 이동이 전부 오탐**이 된다. → 마커(앱 루트 + 경로)로 판정한다.

### T3. 기준을 슬쩍 낮춤
"44px 를 잰다"고 주석에 써 놓고 `if (h >= 32 && w >= 32) return`.
"AA(4.5:1)"라 해 놓고 `if (ratio < 3.0)`.
**주석과 코드가 다르면 코드가 진실이다.** 새 검사를 넣으면 일부러 결함을 만들어 잡히는지 본다.

### T4. 검사 대상이 좁음
`button, [role=checkbox]` 만 보면 **`a[href]`·네이티브 input·`select`·`[role=button]`·`[tabindex]`** 가 통째로 빠진다.

### T5. 죽은 코드
알파 합성 함수를 만들어 두고 **한 번도 부르지 않았다.**
`grep "함수이름("` 으로 정의 외에 호출이 있는지 확인한다.

### T6. 조상을 유효 클릭으로 인정
```js
return hit === el || hit.contains(el)   // ❌ 조상을 눌러도 버튼은 안 눌린다
return hit === el || el.contains(hit)   // ✅
```

### T7. `::after` 확장이 겹침 검사에 안 보임
`getBoundingClientRect` 는 의사 요소를 포함하지 않는다.
히트영역을 넓히면 **이웃의 클릭을 가로챌 수 있는데 겹침 검사가 못 잡는다.**
→ 중심을 `elementFromPoint` 로 눌러 **다른 상호작용 요소가 잡히는지**(`tap-stolen`) 별도 검사.

### T8. 중심 클릭 실패를 조용히 건너뜀
```js
if (!hits(el,0,0)) return;   // ❌ 가로채기를 숨긴다
```
→ 가려진 것(모달·고정바)인지, **가로채인 것**인지 구분해서 후자는 보고한다.

### T9. 화면 밖 좌표를 무조건 통과 처리
뷰포트 밖 요소를 `return true` 로 넘기면, 스크롤해야 보이는 컨트롤이 전부 미검사가 된다.
최소한 **몇 개를 그렇게 넘겼는지 세어** 보고한다.

### T10. 결과를 상한으로 잘라냄
`out.slice(0, 6)` — 7번째 이후의 **서로 다른** 결함이 수집 자체에서 사라진다.
표시만 자르고 **집계는 전부** 한다.

### T10-b. 필터가 검사 자체를 통째로 꺼 버림 🔴🔴
세로 간격 비교에서 부유 요소를 빼려고 `position: absolute` 조상을 제외했는데,
Ionic 이 **페이지마다 붙이는 `.ion-page` 가 absolute** 라
**전 화면의 세로 간격 검사가 통째로 꺼져 있었다.**
그 상태로 낸 **"편차 0"** 을 문서에 적었고, 구멍을 메우자 **33개 화면에서 편차가 다시 나왔다.**

→ 필터를 넣을 때는 **그 필터가 몇 개를 걸렀는지 세어 보고**한다.
```
세로 간격 비교 대상 412개 (부유 제외 18개)   ← 이 줄이 있으면 즉시 알아챈다
```
→ 부유 요소는 `position` 이 아니라 **선택자로 지목**한다.

### T11. 빌드/서버를 책임지지 않음
`audit:all` 이 이미 떠 있는 포트를 조회만 하면 **낡은 `dist`** 나 **엉뚱한 앱**을 검사하고도 통과한다.
→ 러너가 빌드 최신화·서버 기동·정리를 **직접** 하고, 포트가 이미 쓰이면 **멈춘다.**

## 🟡 오탐 — 없는 결함을 만듦

### F1. 가로 스크롤 레일 안의 항목
칩 필터·가로 캐러셀은 **넘치는 것이 설계다.**
조상에 `overflow-x: auto|scroll` 이 있으면 제외한다.

### F2. 모달 스크림을 하단 고정 바로 오인
전체를 덮는 `fixed` 요소는 바가 아니다. **높이가 화면의 40% 미만**일 때만 바로 본다.

### F3. `::after` 히트영역을 글자 넘침으로 오인
`scrollWidth > clientWidth` 인데 **글자가 없는 요소**(체크박스 상자 등)는 넘친 게 아니다.
→ `textContent.trim()` 이 비면 제외.

### F4. 라벨로 감싼 컨트롤
`role=checkbox` 가 `<label>` 안에 있으면 **라벨 전체가 클릭 대상**이다. 라벨을 측정한다.

### F5. 비활성 컨트롤의 대비
`[disabled]`·`[aria-disabled=true]` 는 WCAG 대비 요건 면제다. 제외한다.

### F6. `color-mix()` 결과 오독 🔴
`color-mix()` 의 computed 값은 **`color(srgb 0.98 0.98 0.98 / .62)`** 로 나온다.
0~255 로 읽으면 **흰색을 검정으로** 계산해 없는 결함을 만든다.
```js
const srgb = /^color\(\s*srgb/i.test(c);
const [r,g,b] = srgb ? [n[0]*255, n[1]*255, n[2]*255] : [n[0], n[1], n[2]];
```
알파는 버리지 말고 **아래 배경에 합성**한다.

### F7. 고정 조상을 안 봄
탭바 아래로 스크롤된 요소를 "가려짐"이 아니라 "가로채임"으로 오인한다.
→ 조상 체인에서 `position: fixed|sticky` 를 찾는다 (탭바 '버튼' 자체는 static 이다).

### F8. DOM 순서로 맨 위 오버레이를 정함
세션 만료 카드가 DOM 상 먼저 올 수 있다. **z-index** 로 정한다.

### F9. 애니메이션 종료 전에 측정
`networkidle` 직후에 재면 등장 애니메이션 중간값을 읽는다. **200~300ms 대기.**

### F10. 정렬·간격의 "다양함"을 결함으로 셈 🔑
정렬선이 3가지인 것은 **설계**다(들여쓰기 단계).
**55px 과 59px 이 섞인 것**이 결함이다. → **근접 불일치(2~8px)** 만 보고한다.

### F11. 픽셀 대비로 글자를 판정
픽셀만으로는 글자와 **구분선·아이콘·사진**을 구분할 수 없다.
DOM 이 있으면 DOM 이 권위. 픽셀 대비는 **참고용**으로만.
(픽셀에서 재더라도 획 옆 픽셀이 아니라 **행의 최빈색**을 배경으로 삼아야 한다 —
옆 픽셀은 이웃 획일 수 있어 1.00:1 이 나온다.)

## 검사를 추가할 때의 절차

1. **일부러 결함을 만든다** (버튼을 30px 로 줄이고, 글자를 배경색으로 바꾸고…)
2. 검사기가 **잡는지 확인**한다
3. 원상 복구하고 **0이 되는지 확인**한다
4. 오탐이 나오면 **왜 제외하는지 주석**을 달고 제외한다
5. `실제로 연 수 / 예정 수` 를 보고에 넣는다
